# Lemivanta 微信小程序 · 0.17.0

独立的 Taro + React + TypeScript 客户端，复用上一级 MathAtlas 仓库的数据和纯逻辑，不复制一份课程内容。保留原 Expo App，新增共享课程时两端同步更新；旧 miniprogram-1 测试工程 测试项目未改动。

这是本地开发预览版，不是已上线或通过审核的版本；名称、商标、类目、题源使用范围、隐私声明及备案等仍需运营者确认。

## 当前功能

- 五个底部入口：首页、知识、公式、例题、我的。
- 10 门课程、305 个已完善知识点、321 条公式、1108 道解析题。十轮新增 80 点、720 题，其中 624 题明确标注为参数变式；完整记录见 [1.22.0](../store/content-1.22.0.md)。
- 首页、知识页的“课程拓展路线”：每门目标 70 点，共 700 个目录项，305 已完善、395 待补。每门 7 章，每章 10 项；待补只读，不进入知识库、不支持打开或收藏。“只看已完善”隐藏待补项和空章，编号与目标不变；知识页与详情能带上当前课程。极限与连续、向量与空间、事件与概率、样本与数据描述、过程概念与平稳性五章已分别内容覆盖 10/10，不代表用户学习完成。尚未达成每门 70 个完整知识点。
- 首页、知识页的“教材导学”：4 条资料路线，串联 1.7.0 批次的 12 个专题与 24 道自编题；不打包整书。
- 统一竞赛题库 20 道，保留真题 / 训练题及 A/B 类筛选，列表和详情不显示 PDF 页码。资料真题仍保留核验说明，不冒充已获官方认证。
- 例题提示与解析默认隐藏，展开后可标记完成；知识点和公式可收藏。
- 每日 3 道极限题，复用 42 题及 14 天排题逻辑；保存解题草稿、自评和 28 天学习日历。
- 待复习队列：回看每日题和原草稿，确认掌握后更新原日期自评，不新增今日练习次数。
- 手机验收与反馈页：8 项手动清单与公式样本，默认全部待测。设备信息仅由用户点击读取，结果仅点击后复制，不自动上传。
- 手动导出、检查、合并恢复 JSON 备份。保留旧 App 的 schemaVersion 和 MathAtlas 标识是为了兼容，不是将微信版改回旧品牌。
- 16 篇本地精选论文及搜索、摘要、阅读建议、相关知识点与原文链接复制。**微信版没有在线论文 API 或自动更新**。
- 706 张去重公式图片在构建时生成，以 8 色 PNG 保留原有 1.5 倍像素尺寸，与应用本地打包；不依赖网络公式服务，也不调用普通小程序不支持的 wx.loadSubpackage。

## 在微信开发者工具打开

已经为用户提供的 AppID 配置工程。AppID 不是 AppSecret；仓库不需要密码、密钥或验证码。

1. 保留旧测试项目，不要把新文件粘贴覆盖过去。
2. 微信开发者工具选择“小程序 → 导入项目”。
3. 选择本 README 所在的 mini-program 文件夹，**不是**原 Expo 根目录、src 文件夹或旧 miniprogram-1。
4. project.config.json 中 miniprogramRoot 已指向 dist/；AppID 为 wx44f87bace7f3937f。不使用云服务。
5. 导入已有项目时不再选择或生成模板。点击“编译”，首页应显示 Lemivanta，而不是 Hello World。

工具可能将窗口标题显示为文件夹名 mini-program，不影响应用名称。本轮构建范围见 [0.17.0 记录](../store/content-1.22.0.md)，手机验收仍待用户反馈；此前记录不代表新版本已验收。初版修复见 [0.1.0 记录](../store/wechat-client-0.1.0.md)。

本轮生产主包为 2,024,335 字节，距离项目设置的 2 MiB 保守预算余 72,817 字节。课程内容采用压缩序列化与本地纯 JavaScript 解码，已核对全量内容一致；保留 UTF-8 中文与原有公式图片尺寸。体积阈值未提高，构建通过不代表平台审核或真机验收通过。

## 重建与开发

需要 Node.js 18+；本机已用 Node.js 24.21.0 验证。Taro 固定为 4.2.1、React 为 18.3.1，与原 Expo 的 React/依赖隔离。首轮安装可能较慢，依赖锁定在 package-lock.json。

先按上一级 README 安装原 App 依赖，公式生成会复用上一级已安装的离线 MathJax；然后进入本目录：

```bash
npm ci
npm run typecheck
npm test
npm run build:weapp
```

build:weapp 会生成公式图片、品牌头像缩略图和 dist，然后检查全部页面、图片路径及本地包体积预算。不必在微信工具内再次“构建 npm”。首次构建 Taro 会创建自己的用户缓存目录，环境限制写入时需要批准。

日常改页面可运行：

```bash
npm run dev:weapp
```

开发构建可能大于生产构建；手机预览前用 build:weapp 重新生成生产产物。修改上一级课程内容或头像后，也需要重建，以重新生成公式资源。不要只复制单个页面到 dist；下次构建会覆盖构建产物。

## 目录

- config/：Taro 配置，共享数据编译与静态资源复制。
- src/pages/：微信页面入口与标题。
- src/views/：首页、目录、详情、每日练习、学习记录、备份、论文和隐私界面。
- src/components/：微信组件封装与公式图片显示。
- src/lib/storeCore.ts：可独立测试的本地存储状态逻辑。
- src/lib/study.ts：微信存储适配；只使用 lemivanta:study:v1，不读取原 Expo 的存储。
- scripts/：公式生成、纯逻辑回归及构建产物检查。
- src/generated/、dist/：自动生成且不提交版本库。

## 数据保护与限制

读取失败会暂停自动保存，避免用空记录覆盖旧内容；写入失败不将未保存变更冒称为已保存。清除记录需要二次确认，只移除本小程序自己的存储键。测试脚本只使用内存存储，不读取真实学习记录。

原 App 与微信版不自动同步。备份合并按旧协议保留本机同日期同题的记录，支持重复恢复；旧版自由练习草稿会保留，但本版尚未提供其编辑页。没有接入登录、支付、广告、后台任务或云数据库。

正式发布前仍需手机真机验收、内容使用范围核验、实际主体/类目确认、可用联系信息与隐私政策。不要直接按“上传”就认为已经正式发布。
